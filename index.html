QuizShare

Full-stack e mobile | Authentica S.p.A., Terni | 14-25 settembre 2026

QuizShare è un'app di quiz multiplayer in tempo reale che si gioca da smartphone o browser. Ho curato l'interfaccia Flutter e ingegnerizzato l'intero backend serverless su Supabase e PostgreSQL.

Punti Chiave dello Sviluppo

  • Backend Serverless & RLS: Disegno dello schema database PostgreSQL con regole di sicurezza Row Level Security per la protezione dati.
  • Sincronizzazione Realtime (WebSocket): Compensazione dinamica del clock drift tra server e client per assicurare un timer di countdown perfettamente identico per tutti i giocatori.
  • Calcolo Punteggio via RPC: Risposte e classifiche elaborate atomicamente nel database tramite Stored Procedures (RPC) per prevenire manomissioni lato client.
  • Autenticazione Flessibile & RBAC: Login come ospite (UUID locale) o utente registrato con codice OTP via e-mail e gestione ruoli moderatore.

List-Up!

Front-end mobile | Freeday15 SRL (Authentica Group), Terni | 3-20 giugno 2026

List-Up! è un'applicazione mobile e web per la gestione avanzata di liste e checklist. Ho sviluppato l'architettura client-side in coppia con un collega backendista.

Punti Chiave dello Sviluppo

  • BLoC & Clean Architecture: Separazione netta tra interfaccia, logica dello stato ed erogazione dati per un codice reattivo e modulare.
  • Repository Pattern & Modalità Mock: Livello dati astratto con supporto a sorgente mock per testare l'intera app offline senza server.
  • Dynamic Theme Engine (Material 3): Gestione personalizzata del tema che inietta palette di colori, font Google e Dark Mode in tempo reale.
  • Stato Preservato (IndexedStack): Navigazione tra schermate senza re-rendering dell'interfaccia.

Code Monsters

Front-end web | A Coruña, Spagna | 8 gennaio - 6 febbraio 2026

Code Monsters è un'accademia di programmazione e competenze digitali in Spagna. Nel mio primo stage PCTO all'estero, ho eseguito il refactoring completo del loro sito in Hugo e Bootstrap 5.

Punti Chiave dello Sviluppo

  • Refactoring SCSS Modulare (BEM): Eliminazione delle classi utility Bootstrap dall'HTML sostituendole con classi personalizzate (cm-*).
  • Separazione Struttura e Stile: Organizzazione degli stili in partials (_variables, _buttons, _grid) compilati da Hugo Pipes.
  • Workflow Git & Pull Request: Lavoro in team bilingue (inglese/spagnolo) su branch separati con risoluzione dei merge conflicts.
